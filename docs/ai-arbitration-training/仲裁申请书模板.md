# 劳动人事争议仲裁申请书模板

## 一、AI 生成提示词

```text
你是劳动仲裁文书辅助助手，任务是根据用户提供的案件事实、证据材料和咨询记录，生成一份劳动人事争议仲裁申请书草稿。

【输入信息】
你会收到：
1. 申请人信息：姓名、身份证号、联系方式、住址。
2. 被申请人信息：公司名称、统一社会信用代码、住所地、法定代表人。
3. 劳动关系事实：入职时间、岗位、工资标准、工作地点、合同签订情况。
4. 争议事实：拖欠工资、未签劳动合同、违法解除、加班费、经济补偿等。
5. 证据材料：劳动合同、工资流水、考勤记录、聊天记录、解除通知等。
6. 用户咨询记录：用户曾经描述过的案件经过和诉求。

【生成要求】
请生成一份结构完整、表达正式、适合课堂演示的劳动仲裁申请书草稿，必须包含：
1. 标题
2. 申请人信息
3. 被申请人信息
4. 仲裁请求
5. 事实与理由
6. 证据目录
7. 结尾落款

【依据要求】
- 必须优先依据用户提供的事实和证据生成。
- 不得编造身份证号、公司统一社会信用代码、具体日期、金额或证据。
- 信息缺失时用【待补充】标注。
- 金额计算不确定时，说明“需结合工资流水、考勤记录进一步核算”。
- 不得承诺仲裁结果，不得替代律师或仲裁员作最终法律判断。

【输出格式】
请直接输出仲裁申请书正文，不要输出分析过程。
语言应正式、清晰、克制，适合作为草稿继续人工修改。
```

## 二、仲裁申请书正文模板

```text
劳动人事争议仲裁申请书

申请人：【姓名】
性别：【性别】
身份证号：【待补充】
联系电话：【待补充】
住址：【待补充】

被申请人：【公司名称】
统一社会信用代码：【待补充】
住所地：【待补充】
法定代表人：【待补充】
联系电话：【待补充】

仲裁请求：

1. 请求裁决被申请人支付申请人【拖欠工资/加班费/经济补偿/赔偿金】人民币【待核算】元；
2. 请求裁决被申请人支付申请人未签订书面劳动合同二倍工资差额人民币【待核算】元；
3. 请求裁决被申请人为申请人补缴【待补充期间】的社会保险；
4. 请求裁决被申请人承担本案相关法律责任；
5. 其他请求：【待补充】。

事实与理由：

申请人于【入职时间】入职被申请人处工作，岗位为【岗位名称】，工作地点为【工作地点】，双方约定工资标准为【工资标准】。申请人在职期间，按照被申请人的安排从事相关工作，接受被申请人的管理，双方之间存在劳动关系。

在劳动关系存续期间，被申请人存在以下争议行为：【简要概括争议事实，例如拖欠工资、未签订书面劳动合同、违法解除劳动关系、未依法缴纳社会保险等】。

关于工资支付问题，申请人主张被申请人尚欠【期间】工资人民币【待核算】元。相关事实可由【工资流水/聊天记录/考勤记录/劳动合同】等材料予以证明。

关于劳动合同问题，若双方未依法签订书面劳动合同，申请人主张被申请人应依法支付未签订书面劳动合同二倍工资差额，具体金额需结合入职时间、工资标准及实际工作期间进一步核算。

关于解除劳动关系问题，申请人认为被申请人的解除行为存在【待补充：违法解除/未依法通知/未支付经济补偿】等情形，依法应承担相应责任。

综上，被申请人的行为已经损害申请人的合法劳动权益。为维护申请人的合法权益，特向贵委申请仲裁，请依法支持申请人的仲裁请求。

证据目录：

1. 【劳动合同/入职登记/工牌/工作记录】：证明双方存在劳动关系；
2. 【工资流水/工资条】：证明工资标准及工资支付情况；
3. 【考勤记录/排班表】：证明申请人实际出勤情况；
4. 【聊天记录/通知文件】：证明双方沟通、催款或解除劳动关系情况；
5. 【其他证据】：【待补充】。

此致

【劳动人事争议仲裁委员会名称】

申请人：【姓名】

日期：【年】年【月】月【日】
```

## 三、课堂讲解说法

这个模板解决的是“AI 生成文书容易格式散、事实乱编”的问题。提示词负责告诉 AI 只能依据用户事实和证据生成，不能编造金额、日期和身份信息；正文模板负责固定仲裁申请书的结构，包括申请人、被申请人、仲裁请求、事实理由和证据目录。实际使用时，AI 生成的是草稿，最终还要由用户或专业人员核对事实、金额和法律依据。
