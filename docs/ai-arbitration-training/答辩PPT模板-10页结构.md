# AI 劳动仲裁辅助系统答辩 PPT 模板

> 用途：学生最终答辩参考。建议控制在 10 页，演示 5 分钟，问答 2 分钟。

## 1. 项目标题

- 项目名称：AI 劳动仲裁辅助系统
- 小组成员和分工
- 一句话定位：用 AI + RAG 帮助劳动者完成咨询、证据整理和文书草稿生成

## 2. 业务背景

- 劳动者常见痛点：咨询贵、流程不清、证据不会整理、文书不会写
- 统一案例：张三被拖欠工资并被口头辞退
- 系统目标：给出有依据的初步建议，不替代律师和仲裁员判断

## 3. 核心业务流程

```text
用户提问 → RAG 检索依据 → AI 生成回答 → 证据建议 → 文书草稿 → 人工复核
```

说明每一步输入、处理和输出。

## 4. 系统架构

- 前端：Vue3 + Vite + Element Plus
- 后端：FastAPI + SQLModel + JWT
- AI：OpenAI 兼容模型 + LangChain
- 知识库：ChromaDB / 检索器
- 真实接口：`/ai/chat/*`、`/ai/knowledge/*`

## 5. RAG 链路说明

- 为什么不能只问大模型
- 法律资料如何上传到知识库
- 用户问题如何检索出相关依据
- AI 如何基于依据回答

## 8. 遇到的问题和解决

建议选 3 个真实问题：

- 依赖安装慢：使用 uv 和镜像源
- 检索不准：调整资料切片、问题写法、top_k
- AI 输出不稳定：通过 Prompt 限制输出结构
- 前后端接口不一致：先查真实 API 封装，再设计扩展接口

## 9. 项目亮点

- 回答有依据，不是纯 AI 编答案
- 业务闭环完整，能从咨询走到文书草稿
- 前后端分层清楚，接口口径明确
- 保留人工复核，避免法律场景过度自动化
