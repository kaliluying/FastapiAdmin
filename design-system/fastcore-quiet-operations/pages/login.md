# 登录页

[设计系统](../MASTER.md) · [文档目录](../../../docs/README.md)

> 本文保留该页面设计与当轮验收记录；当前文件或测试脚本若尚未提交，新克隆中不保证包含。复验以[测试与验收](../../../docs/TESTING.md)及现有实现为准。

- 桌面使用内收的品牌面板与直接呈现的表单；左右布局保留约 56% 的品牌列，表单最大宽度 440px。
- 品牌面板用文档叠层与局部点阵表达知识空间，不使用整屏斜纹、营销指标或持续动画。
- 表单标题、独立字段标签和主要按钮形成清晰层级。输入框与登录按钮通常高 52px；短屏输入框收敛至 48px。
- 1180px 及以下隐藏品牌列，优先登录能力；640px 及以下将页面设置收进单个按钮，Escape 关闭并返回焦点。
- 短屏收敛装饰与间距，必要时只滚动表单区域；不得让主要操作被固定页脚遮住。
- 保留左右、居中布局、明暗主题、主题色、语言、校验、验证码重试和现有认证链路。颜色复用项目语义变量，不引入在线字体或新依赖。

## 验证

从 `frontend/` 执行 `node tests/login-e2e.cjs`。复用现有隔离验收启动器，使用临时 SQLite、模拟 Redis 和本机 Chrome；需安装项目依赖并让 Node 可解析 Playwright。

验收覆盖三种布局、明暗主题、375–2048px 宽度、桌面短屏和移动横屏，检查渲染、横向溢出、主要操作可达性、移动设置焦点、字段校验、错误恢复和真实登录。验证码失败通过注入 503 响应验证，重试返回真实隔离接口的挑战；不代表生产数据库或外部 OAuth 服务验收。
