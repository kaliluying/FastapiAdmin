# 首页：知识工作台

## 范围与设计取舍

- 仅调整首页及其 Banner、登录活动组件，不改变共享主题、应用外壳和其他业务页面。
- 第一层是开始 AI 对话、知识库和文档；第二层是管理入口与真实登录活动。移动端先呈现入口，再呈现统计。
- 主任务使用墨蓝底与高对比文字；辅助面板沿用现有语义颜色和用户主题。半透明仅用于主任务区的资源入口，不铺满界面。
- 沿用系统中文字体，标题、正文、辅助文字和真实数字形成层级；不加载远程字体、不新增运行依赖、不放置虚构指标。
- 交互反馈为背景、边框和箭头的短过渡；键盘焦点可见。减少动态效果偏好下禁用过渡，以每日数据表替代动画图表。

质量参考采用 [Awwwards 评估维度](https://www.awwwards.com/about-evaluation/) 和 [Webby 评审标准](https://www.webbyawards.com/judging-criteria/)，侧重视觉、可用性和整体工作体验，而不是移植营销网站的大幅动画。这不是获奖认证。

## 数据与权限

- 所有首页入口仍来自当前用户授权菜单，隐藏、外链、嵌入页和参数路由不进入入口列表。
- 去掉原有的前八项截断，使后排知识库和文档入口能够被找到；主任务入口不在常用入口中重复展示。
- 登录活动仍受 `module_system:login_log:query` 权限控制。
- 健康提示明确标注“基础服务”，不把数据库与 Redis 就绪状态解释为 AI 模型可用性。
- 保留健康轮询、手动刷新、降级与不可用反馈，以及登录趋势加载、失败、空态和重试。
- 查阅 CodeVault 索引后未引入新 Pattern：现有菜单投影、接口和组件已足够，没有新状态管理或抽象的必要。

## 可重复验收

从 `frontend/` 执行：

```sh
pnpm exec vitest run src/views/home/index.spec.ts
pnpm exec vue-tsc --noEmit
pnpm exec vite build
```

浏览器验收从仓库根目录执行，需要可用的 Playwright 与 Chrome：

```sh
node frontend/tests/home-e2e.cjs
```

浏览器脚本复用隔离验收服务：临时 SQLite、模拟 Redis、本地模型替身，不启动业务数据库；占用端口时拒绝复用其他服务。脚本保存多尺寸、深色、空态截图及 `home-results.json`，结束后清理所启动的进程。

## 自检边界

- 排版与留白：移动端缩短资源说明、压缩主任务区；桌面保持明确的主辅分区。
- 视觉层级与色彩：突出可执行入口；统计不使用假增长率；复用图表已有的主题更新机制，避免多余重建与浅色图例残留。首页局部监听图表容器尺寸，修复主题和减少动效切换后的画布裁切，不改共享图表。
- 动效与微交互：44px 以上入口和刷新目标、原生可折叠明细、键盘焦点及带当前状态的读屏名称。
- 响应式：375、768、1024、1440px 无页面横向溢出，首页入口不被裁切。
- 原创性：以知识工作流组织内容，而不是装饰型指标卡、外部图片或营销页模板。
- 真实链路：隔离环境中的登录、授权菜单、健康与趋势接口，以及首页到对话、知识库、文档的导航；错误和空态由显式响应替身验证。
- 已知基线：共享侧栏仍会报 `subMenus.value[index]` 未定义。脚本单独记录这条已知报错，其他运行异常仍失败；本轮未修复该共享组件。隔离环境验收不代表生产环境或真实模型验收。
