## 侧边栏消除下拉折叠（用户反馈"还是下拉格式的"）

根因：侧边栏菜单用 `ElSubMenu` 实现二级菜单的展开/折叠——用户需点击父菜单才能看到子项，这就是用户说的"下拉格式"。用户要的是所有菜单项一次性全部可见的扁平导航。

方案：保留 `ElSubMenu` 组件（不破坏折叠模式的 popup 行为），但强制全部展开 + 禁止折叠交互：

1. **`elMenuRef` + `allSubmenuIndexes` computed**：递归收集 `menuList` 中所有含 `children` 的菜单项 `path`，作为展开 index 列表。
2. **`defaultOpenedMenus = computed(() => allSubmenuIndexes.value)`**：传给 `ElMenu :default-openeds`，初始渲染即全展开。
3. **`watch([allSubmenuIndexes, menuOpen])` + `nextTick` → `elMenuRef.open(idx)`**：菜单数据异步到达或 `menuOpen` 切换时重新强制展开；折叠模式（`menuOpen=false`）跳过，保留 popup 行为。
4. **`:unique-opened="false"`**：允许多个子菜单同时展开（之前 `uniqueOpened` 只允许一个）。
5. **CSS `.el-menu:not(.el-menu--collapse)`**：
   - `.el-sub-menu__icon-arrow { display: none }` 隐藏折叠箭头
   - `.el-sub-menu__title { pointer-events: none; cursor: default }` 禁止点击折叠
   - 子菜单标题 `.menu-name` 弱化为分区标题样式（12px uppercase letter-spacing gray-500）
   - `.menu-icon { opacity: 0.45 }` 弱化父级图标
6. **深色模式适配**：`.dark .layout-sidebar .el-menu:not(.el-menu--collapse) .el-sub-menu__title .menu-name` 用 `rgb(148 163 184 / 72%)`。

验证：`vite build --outDir dist-verify` **`✓ built in 1m 35s` 零报错**。stylelint --fix 通过。
